# Electrician website template

A fast, SEO-ready, fully static electrician website. **Every client detail lives in one file:
`assets/config.js`.** Edit that, drop in the client's photos, and the whole site reskins.

Works on any static host (GitHub Pages, Cloudflare Pages, Netlify). No build step, no server.

## Pages
- `index.html` (home)
- `services.html` + 6 service pages (`fuse-boards`, `rewires`, `ev-chargers`, `eicr-testing`, `emergency-electrician`, `lighting`)
- 10 location pages (`electrician-in-<town>.html`) for local SEO
- `about.html`, `our-work.html`, `reviews.html`, `areas.html`, `contact.html`, `privacy.html`, `404.html`

Header, footer, page content and structured data are all generated by `assets/app.js` from `assets/config.js`.

## Reskin for a new client (5 minutes)
Open **`assets/config.js`** and change:
1. **Business details** — `name`, `phone`, `email`, `area`, `areaShort`, `hours`, `rating`, `reviewCount`, `address`, `geo`, `baseUrl`.
2. **Services** — edit the `services` array (names, copy, FAQs). Add/remove to taste.
3. **Areas** — edit the `locations` array (one page is generated per town).
4. **Reviews** — edit the `reviews` array.
5. **Accent colour** (optional) — the brand blue/amber live in `assets/styles.css` under `:root` (`--brand`, `--accent`).

## Add real photos
Set them in `config.js` under `images`:
- `images.about` — a photo of the team or van (used on Home + About).
- `images.gallery` — an array of job photos (used on Our Work).

Prep each photo first: resize + compress + convert to **WebP** at **squoosh.app**. Target ~1200px wide for hero/gallery, keep each under ~200KB. Put the files in an `images/` folder and reference them, e.g. `images.about = "/images/van.webp"`.

## Add the map
In Google Maps, search the client's town/address → **Share → Embed a map** → copy the `src="..."` value → paste it into `config.js` as `mapEmbed`. It becomes a real interactive map on the Areas + Contact pages. (Also set up a **Google Business Profile** — it's the biggest local-SEO lever.)

## Wire the lead form (GoHighLevel)
1. In GHL: **Automation → Workflows → New → trigger: Inbound Webhook.** Copy the webhook URL.
2. Paste it into `config.js` as `formEndpoint`.
3. In the workflow: Create/Update Contact → Create Opportunity → **SMS + Email the owner** with the lead → auto-reply to the customer.

The form posts JSON: `{ name, phone, postcode, service, message, source }`.

## Deploy to GitHub Pages
1. Create a new repo and upload **the contents of this `site/` folder** to the repo root.
2. Repo **Settings → Pages** → Source: `main` branch, `/ (root)` → Save.
3. Custom domain: add the client's domain in that same Pages screen (creates a `CNAME` file), and point the domain's DNS at GitHub Pages.
4. The included `.nojekyll` file makes sure everything is served as-is.

**Before go-live:** update `baseUrl` in `config.js` and the domain in `sitemap.xml` + `robots.txt` to the client's real domain, then submit `sitemap.xml` in Google Search Console.
